# File Permissions

## Definition

%% recon:start definition %%
chmod 600 means only the owner can read and write the file.
%% recon:end %%

## Notes

%% recon:start from-linux-basics %%
### From [[Linux Basics]], 28 October 2026

- chmod 600 restricts access to the owner only for reading and writing.
- chmod +x adds execute permission to a file.
